## Usage

```shell
npm i @emoji-platform-data/emoji-mart
```

```ts
import { byEmoji, byTitle } from "@emoji-platform-data/emoji-mart";

console.log(byEmoji["🐙"]);
/*
{
	category: "nature",
	id: "octopus",
	keywords: ["animal", "creature", "ocean", "sea", "nature", "beach"],
	name: "Octopus",
	order: 633,
	skins: [{ native: "🐙", unified: "1f419" }],
	version: 1,
}
*/
```

Emojis can be looked up by their glyph with `byEmoji` or by the PascalCase form of their Emojipedia title with `byTitle`.
Each entry is an `EmojiMartItem` containing the data from [emoji-mart](https://github.com/missive/emoji-mart).

`keywords` are the terms emoji-mart's picker matches searches against.
`category` and `order` are where the emoji sits in that picker: which of its eight categories lists the emoji, and where the emoji falls in the overall order.
`skins` is the emoji followed by each of its skin tone variants, so 👋 lists 👋🏻 through 👋🏿 after itself.
`aliases` and `emoticons` are only present for the few emoji that have them: 👍 is also `thumbsup`, and 😃 also stands in for `:)`.

This package contains only static JSON and type declarations: it has no runtime dependencies.
It is one of several data packages generated by the [`JoshuaKGoldberg/emoji-platform-data` repository](https://github.com/JoshuaKGoldberg/emoji-platform-data), which publishes a combined [`emoji-platform-data`](http://npmjs.com/package/emoji-platform-data) package with data from all supported platforms.

## Where This Data Comes From

This data is the Unicode 15 _native_ set from [`@emoji-mart/data`](https://www.npmjs.com/package/@emoji-mart/data), the data package behind [emoji-mart](https://github.com/missive/emoji-mart), the emoji picker Bluesky's web app uses.

That set is a fixed snapshot rather than a moving target: `@emoji-mart/data` last published in April 2024, so its data stops at Unicode 15.
This package therefore adds keywords for emoji the other sources already know, and never emoji of its own.
45 of the emoji in `emoji-platform-data` aren't in it at all, including every emoji added since Unicode 15.
For emoji it does cover, its keywords are unusually good at the abstract ones: 📝 is also `exam`, `quiz`, and `study`, and ⚰️ is also `vampire`, `rip`, and `graveyard`.

The names and keywords are emoji-mart's, under [Missive's MIT license](https://github.com/missive/emoji-mart/blob/main/LICENSE).
No emoji artwork is included: these are text names and keywords only.
