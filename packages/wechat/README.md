## Usage

```shell
npm i @emoji-platform-data/wechat
```

```ts
import { byEmoji, byTitle } from "@emoji-platform-data/wechat";

console.log(byEmoji["👍"]);
/*
{
	aliases: ["+1", "thumbsup"],
	description: "thumbs up sign",
	emoji: "👍",
	tags: ["approve", "ok"],
}
*/
```

Emojis can be looked up by their glyph with `byEmoji` or by the PascalCase form of their Emojipedia title with `byTitle`.
Each entry is a `WeChatItem` containing the data from [WeChat](https://www.wechat.com).

`description` is how WeChat names the emoji and `aliases` are the shortcodes it accepts for it, such as `:+1:` and `:thumbsup:` for 👍.
`tags` are extra terms its search matches, which a little over a third of the emoji have.

This package contains only static JSON and type declarations: it has no runtime dependencies.
It is one of several data packages generated by the [`JoshuaKGoldberg/emoji-platform-data` repository](https://github.com/JoshuaKGoldberg/emoji-platform-data), which publishes a combined [`emoji-platform-data`](http://npmjs.com/package/emoji-platform-data) package with data from all supported platforms.

## Where This Data Comes From

WeChat for macOS ships its emoji search data as a single JSON file, `NgEmojiMap.bundle/gemoji.json`, inside the app.
That file is a copy of [GitHub's emoji list](https://github.com/wooorm/gemoji) as it stood around 2016, so its names are the Unicode names of that era: 👍 is a `thumbs up sign`, and ❤️ a `heavy black heart`.

What it describes is WeChat's emoji search, not WeChat's own animated stickers, which aren't Unicode emoji and aren't included here.

So this package is about coverage rather than keywords.
It lists the 845 emoji WeChat's search recognizes, out of the 1,913 in `emoji-platform-data`, and the shortcodes it matches them by.
The names and tags themselves are nearly all names other sources also know, today or as an older name: only two dozen terms are unique to it, and those are Unicode code point descriptions rather than search terms anyone would type.

The data is read out of an installed copy of WeChat, so -like [macOS](https://github.com/JoshuaKGoldberg/emoji-platform-data/tree/main/packages/macos)- it's built from a snapshot committed to the repository rather than from a dependency.
