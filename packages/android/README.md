## Usage

```shell
npm i @emoji-platform-data/android
```

```ts
import { byEmoji, byTitle } from "@emoji-platform-data/android";

console.log(byEmoji["🐙"]);
/*
{
	emoji: "🐙",
	keywords: ["animal", "creature", "kraken", "octopus", "sea", "squid", "tentacle"],
}
*/
```

Emojis can be looked up by their glyph with `byEmoji` or by the PascalCase form of their Emojipedia title with `byTitle`.
`byEmoji` knows each emoji by every glyph platforms write it as, with or without the U+FE0F variation selector, so `byEmoji["⚓️"]` as macOS writes it and `byEmoji["⚓"]` as Twemoji does are the same entry.
Each entry is an `AndroidItem` describing one emoji as Gboard -the keyboard Google ships with Android- knows it.

`keywords` are the terms Gboard's emoji search finds the emoji by, in English, sorted.
There are 17,183 of them across 1,872 emoji, averaging 9.18 each, and over a quarter of them are in no other source in `emoji-platform-data`: 😂 alone answers to `lulz`, `rotfl`, `kidding`, and `hahahahaha`.

This package contains only static JSON and type declarations: it has no runtime dependencies.
It is one of several data packages generated by the [`JoshuaKGoldberg/emoji-platform-data` repository](https://github.com/JoshuaKGoldberg/emoji-platform-data), which publishes a combined [`emoji-platform-data`](http://npmjs.com/package/emoji-platform-data) package with data from all supported platforms.

## Where This Data Comes From

Android's own open source keyboard doesn't search emoji, and Gboard, which does, is closed source.
Gboard ships with its English emoji search data bundled, though, as a small dictionary inside the app, and Google publishes the app inside the Android emulator's system images.
That dictionary was read out of the newest stable Android system image with Google Play and committed as a snapshot, so that building this repository doesn't depend on a network fetch.
See [`DEVELOPMENT.md`](https://github.com/JoshuaKGoldberg/emoji-platform-data/blob/main/packages/android/DEVELOPMENT.md) for how that extraction works and how to refresh it.

Gboard can download newer emoji data, and data for other languages, once it's installed.
Only what it ships with is here.
The data also has no names, categories, or picker order: Gboard's picker takes those from elsewhere.

The keywords are Google's.
This package's MIT license covers the code that extracts and packages them, not the underlying data.
No emoji artwork is included: these are text keywords only.
