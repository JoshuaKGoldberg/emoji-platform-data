## Usage

```shell
npm i @emoji-platform-data/discord
```

```ts
import { byEmoji, byTitle } from "@emoji-platform-data/discord";

console.log(byEmoji["👍"]);
/*
{
	aliases: ["+1", "thumbup", "thumbs_up"],
	category: "people",
	emoji: "👍",
	name: "thumbsup",
	order: 134,
	unicodeVersion: 6,
}
*/
```

Emojis can be looked up by their glyph with `byEmoji` or by the PascalCase form of their Emojipedia title with `byTitle`.
Each entry is a `DiscordItem` describing one emoji as Discord's own emoji picker knows it.

`name` is the shortcode Discord writes the emoji as, and `aliases` are the others it accepts: typing any of them between colons sends the emoji.
Those shortcodes are also what the picker matches searches against, so most emoji have exactly one term and 394 of the 1,932 have more.
`order` is where the emoji falls in the picker's overall order, counting from the first emoji of its first category.

This package contains only static JSON and type declarations: it has no runtime dependencies.
It is one of several data packages generated by the [`JoshuaKGoldberg/emoji-platform-data` repository](https://github.com/JoshuaKGoldberg/emoji-platform-data), which publishes a combined [`emoji-platform-data`](http://npmjs.com/package/emoji-platform-data) package with data from all supported platforms.

## Where This Data Comes From

Discord doesn't publish its emoji list: it ships inside the web client's JavaScript bundle, which its desktop app loads too.
The data here was read out of that bundle and committed as a snapshot, so that building this repository doesn't depend on a network fetch of a file that changes name on every deploy.
See [`.github/DEVELOPMENT.md`](https://github.com/JoshuaKGoldberg/emoji-platform-data/blob/main/.github/DEVELOPMENT.md) for how that extraction works and how to refresh it.

Discord's picker also lists every skin tone variant of the emoji that have them.
Those are left out here: their shortcodes are mechanical suffixes on the base emoji's, such as `wave_tone3`, so they carry no terms of their own.

The shortcodes, categories, and ordering are Discord's.
This package's MIT license covers the code that extracts and packages them, not the underlying data.
No Discord emoji artwork is included: these are text names only.
